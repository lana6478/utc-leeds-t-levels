## What each site is

Every linked site follows the same pattern:

- An organised, plain-English study guide covering the qualification's official specification, cross-referenced to the spec's own numbering.
- A searchable, Wikipedia-style wiki (`docs/`) with a sidebar directory tree, built for GitHub Pages.
- The exact same content as a plain markdown file library (`content/`) in the same repository, for anyone who'd rather browse or download the raw files.

Each qualification gets its own repository and its own GitHub Pages site, all linked from this hub.

## Is this official?

No. This project (this hub and every site it links to) is **independent and unofficial** - not produced or endorsed by UTC Leeds, Pearson, NCFE, City & Guilds, or the Institute for Apprenticeships and Technical Education (IfATE). Always check the official specification and your course provider for anything assessment-critical.
